# 🏛️ موقع مكتب أبونا التفاعلي ثلاثي الأبعاد (3D Office & Admin Panel)

موقع ويب تفاعلي بالكامل بنظام **3D Stylized Office**، مع **لوحة تحكم إدارية (Admin Dashboard)** ديناميكية للتحكم الكامل في محتويات الغرفة، الكتب، المشاريع، الملفات، ورسائل الزوار.

---

## 🌟 مميزات المشروع

### 1. المشهد ثلاثي الأبعاد (Interactive 3D Experience)
* **غرفة مكتب دافئة وعصرية (Warm Stylized 3D):**
  * أرضية خشبية مع سجادة دافئة وحوائط مريحة مع شباك يطل على الضوء الطبيعي.
* **القطع التفاعلية في المشهد:**
  * **🚪 ضلفة المكتبة:** تنفتح بمفصلات حقيقية لتكشف عن السيرة الذاتية والشهادات.
  * **📚 رف الكتب:** مجسمات كتب ملونة، كل كتاب يفتح مشروعاً مفصلاً مع روابط تحميل (PDF/فيديو).
  * **🗄️ أدراج المكتب:** تنزلق للأمام بسلاسة لتفتح قائمة الخدمات والأسعار والملفات المجانية.
  * **🖼️ الصور والشهادات على الحائط:** زووم سينمائي ناعم لعرض المحطات التاريخية والدروع.
  * **💻 اللابتوب على المكتب:** شاشة مضيئة تفاعلية لعرض أحدث المشاريع الرقمية.
  * **☎️ التليفون / صندوق البريد:** نموذج تواصل مباشر وسريع يرسل الرسائل لصندوق لوحة التحكم.
  * **💡 أباجورة المكتب:** مفتاح إضاءة حقيقي يبدل بين **وضع النهار ☀️** و**وضع الليل 🌙** مع تأثيرات إضاءة ديناميكية كاملة للغرفة.
* **حركات سينمائية كاميرا:** زووم سلس مع مؤثرات صوتية فيزيائية خفيفة وزر للرجوع للمشهد العام.
* **شريط تنقل سريع (Quick Navigation):** للوصول الفوري لأي قسم مباشرة دون دوران.
* **نوافذ زجاجية عصرية (Glassmorphism Modals):** لعرض تفاصيل كل عنصر بأناقة.

---

### 2. لوحة التحكم الإدارية (Admin Dashboard)
* **🔐 تسجيل دخول آمن (Auth):**
  * نظام حماية مسارات بـ **JWT Tokens** وتشفير كلمات المرور بـ **Bcrypt**.
* **🛋️ إدارة عناصر المشهد 3D:**
  * تفعيل / تعطيل أي قطعة، تعديل المسميات والـ Tooltips، وتغيير الأقسام المرتبطة.
* **📚 إدارة المحتوى (Content Management):**
  * إضافة وتعديل وحذف المشاريع، الكتب، والخدمات مع تحديد ألوان الكتب والشارات والوسوم.
* **📬 صندوق رسائل الزوار (Inbox):**
  * استقبال الرسائل القادمة من تليفون المكتب مع إمكانية تمييزها كمقروءة وحذفها.
* **🖼️ مكتبة الوسائط (Media Library):**
  * رفع ملفات الـ PDF والصور مع ميزة نسخ الرابط المباشر بضغطة زر.
* **⚙️ إعدادات الموقع والمشهد:**
  * تعديل عنوان الموقع والنبذة، تحديد وضع الإضاءة الافتراضي، وتحديث روابط السوشيال وكلمة المرور.

## 🚀 تشغيل المشروع محلياً

```bash
# 1. التثبيت (تم التثبيت بالفعل)
npm install

# 2. بدء تشغيل السيرفر
npm start
```

### الروابط المباشرة:
* **🌐 واجهة المشهد 3D التفاعلي:** [http://localhost:3000](http://localhost:3000)
* **🔑 لوحة تحكم الأدمن:** [http://localhost:3000/admin](http://localhost:3000/admin)
* **🚪 صفحة تسجيل الدخول:** [http://localhost:3000/login](http://localhost:3000/login)

### بيانات الدخول الافتراضية للمشرف:
* **البريد الإلكتروني:** `admin@office.com`
* **كلمة المرور:** `admin123`
*(يمكن تغييرها في أي وقت من تبويب "إعدادات المشهد" داخل لوحة التحكم)*

## 🛠️ البنية التقنية (Tech Stack)
* **Three.js + GSAP:** محرك المشهد الثلاثي الأبعاد وحركة الكاميرا والفيزياء.
* **Node.js + Express:** خادم الـ API والـ Static Assets.
* **JSON Database (Atomic & Zero-Dependency):** قاعدة بيانات سريعة وموثوقة ولا تتطلب إعدادات معقدة وتعمل فوراً على أي بيئة.
* **Multer:** لرفع وتخزين الملفات والصور والـ PDF محلياً.
* **HTML5 / CSS3 (Glassmorphism & Flex/Grid):** تصميم متجاوب فائق الأناقة مع دعم كامل للغة العربية.
